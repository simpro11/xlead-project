Step 1: Get Your Telegram User ID

First, you need to find your unique User ID from a helper bot.

  1. Open Telegram and search for this bot:
    @userinfobot
  2. Start the bot. It will immediately send you your User ID.
  3. Copy that ID and paste it into the input field below.

Step 2: Start Our Notification Bot

Finally, you must start our bot to allow it to send you messages.

  1. Search for our official bot:
    @X_LeadsBot
  2. Start the bot. That's it! You will now receive lead notifications.
